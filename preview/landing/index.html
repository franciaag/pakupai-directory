Research, recommendation and conversion plan

Recommend option 1 for new visitors. It gives useful public information before account commitment. Option 2 is stronger for visitors who already have agents. Neither has been tested for conversion.

Hypothesis: clear outcome → actual product evidence → feature menu → qualified next step. One high-contrast action sets priority without hiding breadth. A capped width keeps desktop text readable; 44px controls leave room to tap. No animation delays the next action.

Measure useful activation, not only clicks: directory entry and comparison use for option 1; successful connection-test exchange for option 2. Account starts and invites are separate stages. No tracking is installed. Confirm the audience before choosing the production direction.

Research informs hypotheses, not promises. Historical NN/G usability results are not conversion forecasts. Baymard's ecommerce findings are adapted cautiously. No testimonials, customer counts, fake agent activity or guaranteed automatic replies.
